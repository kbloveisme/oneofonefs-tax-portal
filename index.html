Core Product Features

Onboarding & Leveling

Users choose a religion track and start at Beginner, Intermediate, or Advanced with adaptive progression.

Beginner Module

Every topic is explained through Who, What, When, Where, Why, and How for accessible learning.

Storyteller Sessions

Chapters unfold as narrative learning sessions grounded in official text references.

Holy Text Library

Download canonical text sets for offline reading with direct verse/line-level citations in lesson summaries.

Omni-Compare

Compare up to four religions and map conceptual similarities, terms, and shared values respectfully.

Editorial Workflow

Draft → scholarly/religious review → publish with versioning and audit logs for trust and traceability.

Target Architecture

Client Apps

  • React Native app for iOS + Android
  • React web app for browser users
  • Shared design system + analytics schema

Backend

  • Node.js API (NestJS/Express)
  • PostgreSQL for core entities
  • Redis for caching/session workloads

Data + Content

  • Structured lesson + citation schema
  • Vector/keyword search for compare insights
  • Encrypted object storage + CDN for media/texts

Security + Compliance

  • JWT auth + RBAC admin tooling
  • WAF, rate limiting, IAM least privilege
  • Audit logs, backup/restore, privacy disclosures
